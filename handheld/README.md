# Ternary handheld (early ideas)
Working name, if the rights can be had: **The Interociter** (after the interocitor in *This Island Earth*).

The point: put balanced ternary in a familiar, friendly package, so people can play with it and look inside
instead of meeting it in a dense paper.

## Design rules (Kham, 2026-11-20)
- **No pouch cells ("spicy pillows").** Hard-cased, swappable cells only; Nokia BL-5C is the test candidate.
- **Right to repair:** as user-serviceable as possible. Screws, not glue. More than one screwdriver is fine, but
  no specialty security screws.
- **No FPGA.** Same rule as the card computer: the ternary lives in the hardware's structure.

`IDEAS-2026-11-14.md` is the first ideas session as logged (trit pixels, triangular subpixels, a ladder toward
real hardware).
